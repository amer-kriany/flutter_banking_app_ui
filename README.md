## ✨ Features

- 🎨 Pixel-perfect Figma to Flutter conversion
- 💳 Credit card UI with glassmorphism effect
- 🔐 PIN code screen with fingerprint support
- 📊 Transaction history (income & expenses)
- 👥 Quick send to recent contacts
- 🧭 Custom bottom navigation bar
- 📐 Clean layout with custom fonts (Montserrat)
- 🌙 Consistent dark/light color scheme

- [Flutter](https://flutter.dev/) — UI framework
- [Dart](https://dart.dev/) — Programming language

## 🚀 Getting Started

### Prerequisites

- Flutter SDK `>=3.0.0`
- Dart SDK `>=3.0.0`

### Installation

```bash
# Clone the repo
git clone https://github.com/amer-kriany/flutter_banking_app_ui.git

# Navigate to project
cd flutter_banking_app_ui

# Install dependencies
flutter pub get

# Run the app
flutter run
```
